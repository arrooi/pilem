# Pilem

Pilem adalah aplikasi Android untuk menjelajahi, mencari, dan menonton film serta series dari LK21. Aplikasi ini dibuat untuk ponsel, tablet, dan Android TV.

## Fitur Utama

- Beranda dengan beberapa baris konten seperti film unggulan, film terbaru, series unggulan, dan kategori lainnya.
- Pencarian film dan series berdasarkan judul.
- Filter konten berdasarkan tipe (film/series), genre, negara, tahun, dan urutan.
- Halaman detail dengan informasi film/series, rating, durasi, genre, sinopsis, pemeran, sutradara, dan negara.
- Pemutar video dengan dukungan HLS, DASH, dan video progresif.
- Pilihan server/streaming dan fallback ke WebView atau browser jika pemutar gagal.
- Lanjutkan menonton dari posisi terakhir, termasuk season dan episode untuk series.
- Daftar favorit.
- Pengaturan tampilan: tema terang/gelap/sistem, warna latar, dan ukuran font.
- Dukungan navigasi untuk TV dengan mode layar penuh.

## Cara Menggunakan

1. Buka aplikasi, lalu jelajahi konten di halaman Beranda.
2. Gunakan tombol **Cari** untuk mencari judul film atau series.
3. Gunakan tombol **Filter** untuk mempersempit hasil berdasarkan genre, negara, tahun, dan urutan.
4. Buka detail film/series, lalu pilih server dan tekan putar.
5. Untuk series, pilih season dan episode yang diinginkan.
6. Gunakan **Favorit** untuk menyimpan konten yang ingin ditonton lagi.
7. Atur tampilan di menu **Pengaturan**.

## Catatan

- Aplikasi membutuhkan koneksi internet.
- Konten berasal dari sumber eksternal; ketersediaan dan kualitas stream dapat berubah sewaktu-waktu.
- Beberapa stream dilindungi Cloudflare, sehingga aplikasi akan mencoba metode putar alternatif atau membuka di browser.
- Fitur unduh dapat diarahkan ke browser karena pembatasan keamanan pada beberapa tautan.

## Persyaratan Perangkat

- Android 8.0 (API 26) atau lebih baru.
- Koneksi internet stabil untuk streaming.

## Instalasi

Unduh APK dari halaman **Releases** GitHub, lalu instal di perangkat Android. Jika membangun dari kode sumber, gunakan berkas APK rilis yang tersedia di `app/release/app-release.apk`.
